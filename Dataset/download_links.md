## 🔍 Dataset Components

The complete dataset includes:

| Component        | File name | Description                           |
|------------------|-----------|---------------------------------------|
| Left Images      | ImageL    | Satellite stereo left images          |
| Right Images     | ImageR    | Satellite stereo right images         |
| Disparity Maps   | Disp      | High-precision disaprity ground truth |
| Metadata Files   | Meta      | Stereo imaging parameters             |
